# 初次諮詢資料保護設計

更新日期：2026-11-02。範圍：consult/index.html 及其載入的表單腳本、樣式；不是整個網域或 LINE 後端稽核。

## 資料最小化

- 必填僅稱呼（可用暱稱）與服務類型；手機選填，未填時用客戶自行發起的 LINE 對話聯絡。
- 保留需求金額、用途、縣市、聯絡時段、物品品牌／年份／大致狀況與是否有貸款／分期，均選填。
- 收入與每月現有還款總額改為可略過的區間選項；不要求精確金額或逐筆明細。
- 移除身分證字號與完整字號開關、生日／年齡、詳細居住／戶籍地址及持有人、雇主／年資、薪轉勞保、駕照、銀行與信用卡明細、協商／法扣／警示／支付命令／罰單／呆帳／遲繳、送件與代辦紀錄。
- 正式審核所需資料應在確認需求後，由專人說明用途與提供方式；本頁不負責審核、承諾額度或自動決策。

## 資料流與防護

1. 明確欄位白名單產生摘要，不序列化整份表單或 URL 上的個資。只讀取既有 type 服務代碼，不把姓名、手機等網址參數帶入表單。
2. 在摘要生成與複製邊界，移除常見格式的疑似身分證／新舊居留證號碼及 12 碼以上數字串；支援大小寫、全形、常見分隔及零寬字元。這是減少誤傳的輔助，不是能辨識所有個資的保證，地址等內容仍需人工核對。
3. 摘要唯讀，要求核對後才能按複製；修改表單會使摘要與確認失效。Clipboard API 失敗時改用選取／複製，仍失敗則明確提示手動長按。
4. LINE 永遠使用固定既有官方網址 https://line.me/R/ti/p/@104faknx，不附摘要、姓名、電話或其他客戶內容；由客戶自己貼上與送出。
5. 本頁載入的三支腳本無 fetch、XHR、Beacon、WebSocket、Cookie、localStorage、sessionStorage、IndexedDB 或分析追蹤呼叫。無新增後端、資料庫、上傳、第三方腳本或表單收件服務。
6. 頁面 CSP 禁止 connect-src、form-action、object-src、frame-src 與 base-uri；僅允許本站資源及指定 JSON-LD hash。no-referrer 限制連結的來源資訊；沒有 CSP 回報端點。CSP 是額外防護，不代表同源程式永遠不會被修改。
7. 清空按鈕、初始化及歷史頁面恢復會清除頁面內容。關閉／離開時也嘗試清空；不能保證作業系統強制結束、瀏覽器擴充或外部剪貼簿歷史的處理。清空本頁無法刪除裝置剪貼簿、LINE 訊息或既有副本。
8. 網頁主機與 LINE 仍可處理一般連線紀錄；送出後的 LINE 訊息由其平台及台茂處理。頁面明確提示這項界線，並提供既有電話與官方 LINE 供更正／刪除聯絡。

## 驗證

執行 `node --test tests/consult-privacy.test.cjs`（Node.js 20+，無需安裝套件）。測試使用合成資料，不含真實客戶個資。

14 項自動化測試涵蓋：證件格式與字元變化、帳號卡號、手機格式、最低填寫、選填評估、舊欄位排除、驗證失敗、核對後複製、複製時再檢查、摘要失效、複製拒絕與手動備援、非同步複製與清空競態、頁面清空／歷史恢復、固定 LINE 網址與無網路／儲存程式的靜態檢查。

瀏覽器人工檢查涵蓋：桌面摘要產生與移除提示、確認後複製狀態，以及 iframe 390px／320px 寬度的最低填寫、摘要可讀性與無橫向溢出。這是響應式尺寸測試，不等於實體 iPhone／Android 的 LINE App 交接實測。測試不對外傳送諮詢訊息。

更新 head 內 JSON-LD 時，須同步更新 CSP 的 SHA-256 hash。更新前端檔案時須更新 HTML 的版本查詢字串，避免舊版腳本快取混用。
